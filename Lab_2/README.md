# Lab 2 — Image Processing: Contrast & Order Statistics

Десктопное приложение на Python/Tkinter для повышения контраста изображений и фильтрации нелинейными фильтрами на основе порядковых статистик.

**Вариант:** №5 (построение и эквализация гистограммы + нелинейные фильтры).

---

## Возможности

- Загрузка полутоновых и цветных изображений, добавление шума «соль и перец», сравнение всех методов в один клик.
- Вкладка **«Гистограммы и контраст»**:
  - линейное контрастирование;
  - эквализация гистограммы для полутоновых изображений;
  - поканальная эквализация RGB;
  - эквализация только яркости в пространстве HSV;
  - визуализация гистограмм до/после и расчёт метрик (min, max, mean, std, энтропия).
- Вкладка **«Порядковые статистики»**:
  - генерация импульсного шума;
  - медианный фильтр, фильтр минимума и максимума;
  - фильтр k-й порядковой статистики с настраиваемым рангом;
  - оценка качества фильтрации по PSNR.
- Обработка граничных случаев: пустой диапазон яркостей, полностью чёрное изображение, шум 100 %.

## Формулы и методы

### Линейное контрастирование

f′(m, n) = 255 / (f_max − f_min) · (f(m, n) − f_min)

### Эквализация гистограммы

1. Гистограмма h(i), i = 0…255.
2. Нормализация: h′(i) = h(i) / H, H = Σ h(i).
3. Кумулятивная сумма: Sh(i) = Σ_{j=0}^{i} h′(j).
4. Новые значения: f′(m, n) = 255 · Sh(f(m, n)).

### Цветная эквализация

- **RGB:** поканально применяется эквализация к R, G, B.
- **HSV:** эквализация только компоненты V, каналы H и S не изменяются.

### Порядковые статистики

Отклик фильтра — значение элемента, находящегося на позиции `rank` в упорядоченном по возрастанию массиве пикселей окрестности k×k:

| Фильтр | Ранг |
|---|---|
| Минимума | 0 |
| Медианный | (k·k − 1) / 2 |
| Максимума | k·k − 1 |
| k-я статистика | задаётся пользователем |

### Оценка качества

PSNR = 10 · log₁₀(255² / MSE), где MSE — средний квадрат разности с эталонным изображением.

- `to_tk`, `get_hist`, `hist_to_image` — утилиты отображения;

## Реализация граничных случаев

| Случай | Проблема | Решение |
|---|---|---|
| f_max = f_min (однородное изображение) | Деление на ноль при линейном контрастировании | Возвращается копия исходного изображения |
| Пустая гистограмма | `log1p` от нуля, деление на max | Проверка `hist.max() > 0`, иначе нулевая визуализация |
| Некорректный ранг | `rank` вне диапазона `[0, k·k − 1]` | Проверка и вывод сообщения об ошибке |
| Шум 100 % | Полностью испорченное изображение | Метрики корректно показывают низкий PSNR, фильтры всё равно работают |
