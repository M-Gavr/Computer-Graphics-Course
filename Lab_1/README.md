# Lab 1 — Color Models: CMYK ↔ RGB ↔ HLS

Интерактивное веб-приложение для изучения цветовых моделей **RGB**, **CMYK** и **HLS** с автоматическим пересчётом значений при изменении любой координаты.

**Вариант:** нечётный (CMYK – RGB – HLS).

## Теория

Цветовые модели и преобразования разобраны в лекции:

- [Лекция 1 — Цвет в компьютерной графике. Цветовые модели](../docs/lecture-01-color-models.pdf) — RGB, CMYK, HLS и формулы переходов между ними.

---

## Возможности

- Три способа задания цвета в каждой модели: ползунок, числовое поле, палитра/HEX.
- Мгновенный пересчёт во всех трёх моделях при любом изменении.
- Блок предпросмотра текущего цвета.
- Цветовая индикация ползунков (заполнение трека и «бегунок» в цвете канала).
- Обработка граничных случаев: K = 1, S = 0, Δ = 0.

---

Открыть файл `lab-01-color-models.html` в любом современном браузере. Внешних зависимостей нет.

## Диапазоны величин

| Модель | Координаты | Диапазон |
|---|---|---|
| RGB | R, G, B | 0–255 |
| CMYK | C, M, Y, K | 0–100 % |
| HLS | H | 0–360° |
| HLS | L, S | 0–100 % |

---

## Формулы преобразований

### RGB → CMYK

r = R/255, g = G/255, b = B/255

K = 1 − max(r, g, b)

Если K = 1: C = M = Y = 0. Иначе:

C = (1 − r − K) / (1 − K)
M = (1 − g − K) / (1 − K)
Y = (1 − b − K) / (1 − K)

### CMYK → RGB

R = 255 · (1 − C)(1 − K)
G = 255 · (1 − M)(1 − K)
B = 255 · (1 − Y)(1 − K)

---

### RGB → HLS

max = max(r, g, b), min = min(r, g, b), Δ = max − min

L = (max + min) / 2

Насыщенность:
- Δ = 0: S = 0;
- L ≤ 0.5: S = Δ / (max + min);
- L > 0.5: S = Δ / (2 − max − min).

Тон (при Δ ≠ 0):
- max = r: H = ((g − b) / Δ) mod 6;
- max = g: H = (b − r) / Δ + 2;
- max = b: H = (r − g) / Δ + 4.

H = H · 60°; при H < 0 прибавляется 360°.

### HLS → RGB

При S = 0: R = G = B = L · 255. Иначе:

c = (1 − |2L − 1|) · S
x = c · (1 − |(H / 60) mod 2 − 1|)
m = L − c / 2

| H | (r', g', b') |
|---|---|
| [0, 60) | (c, x, 0) |
| [60, 120) | (x, c, 0) |
| [120, 180) | (0, c, x) |
| [180, 240) | (0, x, c) |
| [240, 300) | (x, 0, c) |
| [300, 360) | (c, 0, x) |

R = round((r' + m) · 255)
G = round((g' + m) · 255)
B = round((b' + m) · 255)

## Структура кода

- `<style>` — вёрстка, карточки моделей, стили ползунков.
- `topbar` — палитра, предпросмотр, HEX-поле.
- `columns` — три карточки: RGB, CMYK, HLS.
- `<script>`:
  - `state` — единое состояние { r, g, b };
  - `rgbToHex` / `hexToRgb`;
  - `rgbToCmyk` / `cmykToRgb`;
  - `rgbToHls` / `hlsToRgb`;
  - `fillRange` — заливка трека ползунка;
  - `render` — пересчёт всех моделей и обновление UI.

## Реализация граничных случаев

| Случай | Проблема | Решение |
|---|---|---|
| K = 1 (чёрный) | Деление на (1 − K) = 0 | `rgbToCmyk` возвращает {c:0, m:0, y:0, k:100} |
| Δ = 0 (серый, чёрный, белый) | Тон H не определён | H = 0, S = 0; при S = 0 обратное преобразование даёт серый независимо от H |
| Накопление ошибок | Дрейф значений при повторных пересчётах | Единое состояние `state`; `Math.round` при переходе в RGB |
| Ввод HEX | Перезапись поля во время набора | Обновление только если поле не в фокусе |
